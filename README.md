# Peak UI V2

Intelex detail-page overlay assets using the Intelex application UI branding system.

## Hosted assets

```html
<link rel="stylesheet" href="https://davemclean-at-summit.github.io/peak-ui-v2/peak-ui.css">
<script src="https://davemclean-at-summit.github.io/peak-ui-v2/peak-ui.js" defer></script>
```

The extensionless `PeakUI_CSS_1.3` and `PeakUI_Scripts_V1.3` files remain the source deliverables. The `.css` and `.js` files are identical copies provided so web servers return browser-compatible MIME types.
